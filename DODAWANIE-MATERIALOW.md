# Dodawanie materiałów

Pliki PDF i GIF umieszczaj w folderze `wyklady`. W `index.html` sekcja Analiza I zawiera elementy `<article class="material">`. Skopiuj taki element, zmień nazwę i ścieżkę PDF-u. Pod nim możesz umieścić dowolną liczbę elementów `<details class="animation">`, zmieniając podpis (Animacja 1, Animacja 2…) i `src` obrazka.

Materiały Analizy II dodawaj w drugim `<details class="course">`, zastępując informację o braku materiałów.

Możesz utworzyć podfoldery `wyklady/analiza-i` i `wyklady/analiza-ii`; wtedy podaj te ścieżki również w linkach. Obecne pliki zachowano w miejscu, aby nie zmieniać istniejących adresów. Samo dodanie pliku nie tworzy linku na stronie — należy też dodać wpis w HTML.

Podgląd: Live Server. Publikacja: GitHub Desktop → Commit → Push origin.
